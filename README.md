## 🦕 О проекте

**Долбазавр RPG (D-Rex)** — игровой проект на Python, который доказывает, что для приключений необязательно быть человеком. Иногда достаточно быть динозавром. Желательно не самым сообразительным.

Проект поддерживает два варианта запуска: графический интерфейс и консольный режим. Выбирайте подходящий способ взаимодействия и отправляйтесь навстречу динозавровым приключениям!

### 🧠 Главная философия

- 🦖 Динозавры — это серьёзно.
- 🧠 Интеллект — необязательная характеристика.
- 💥 Последствия — обязательная часть приключения.
- 🎮 Главное — получать удовольствие.

## 🚀 Установка и запуск

### Требования

- Python 3.x
- Файлы проекта `D-Rex.py`, `game.py` и `window.py`

### Запуск графического режима

```bash
python D-Rex.py
```

### Запуск консольного режима

```bash
python D-Rex.py --console
```
